# 🛒 SyzarSoft Store

## 🚀 Overview
**SyzarSoft Store** is an Android application that serves as an online shop for selling software activation keys.

## ⚡ Key Features
- Browse a list of activation keys
- View detailed product information
- Add products to the Favorites.
- Checkout and secure payment.
